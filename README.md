# StepUp — AI 창업 로드맵 코치 (프론트엔드)

문화예술 분야 청년 창업가를 위한 AI 사업계획서 로드맵 코치 서비스의 프론트엔드 디자인입니다.
아이디어 발굴부터 7단계 사업계획서 작성, 정부지원사업 자동 매칭까지의 화면을 담고 있습니다.

## 화면 구성

| 파일 | 화면 |
|------|------|
| `index.html` | 랜딩 페이지 (히어로 · 7단계 로드맵 · 지원사업 매칭 · 작성 화면 미리보기) |
| `dashboard.html` | 대시보드 (로드맵 진행 상황 · 다음 과제 · 추천 지원사업) |
| `workshop.html` | 로드맵 작업실 (현재 단계 작업 · 실시간 지원사업 매칭) |
| `step-1.html` ~ `step-7.html` | 7단계 작업 상세 (단계별 프레임워크 + AI 초안 생성) |

### 7단계 로드맵
1. **아이디어 스파크** — 문제 발견과 솔루션 (TPCS 프레임워크)
2. **예술적 비전** — 독창성과 차별화 정립 (비전 캔버스)
3. **시장 적합성** — 시장·고객 검증 (TAM·SAM·SOM)
4. **재무 지도** — 비즈니스 모델과 수익 구조 (수익 모델)
5. **투자 유치** — 자금 계획과 지원사업 (자금 계획)
6. **팀 빌딩** — 팀 구성과 실행 체계 (팀 설계)
7. **런칭 데이** — 피치덱과 런칭 준비 (런칭 준비)

각 단계 페이지의 **"AI 초안 생성 시작"** 버튼을 누르면 프레임워크 항목이 자동으로 채워지고 코치 피드백이 표시됩니다(데모용 목업 — 실제 LLM·RAG 연동 지점).

페이지 연결: `index → dashboard → step-1 … step-7`(이전/다음으로 순차 이동), 사이드바로 단계 직접 이동.

## 실행 방법

빌드·설치가 필요 없는 **순수 정적 HTML + 인라인 스타일 + 바닐라 JS**입니다.

```bash
open index.html   # 또는  npx serve .  /  python3 -m http.server
```

GitHub Pages: Settings → Pages → Branch `main` / root.

## 디자인 시스템

| 토큰 | 값 | 용도 |

| Navy | `#2F3E72` | 로고 · 제목 · 주요 버튼 |
| Indigo | `#5A5BD6` | AI · 강조 · CTA · 활성 메뉴 |

- 아이콘: 인라인 SVG · 아바타/이미지: 플레이스홀더

## Claude Code 작업 메모

- 모든 스타일은 인라인 `style`. 필요 시 컴포넌트화/CSS 분리.
- 단계 페이지(`step-*.html`)는 동일한 구조를 공유 — 컴포넌트화 시 props로 단계 데이터만 분리하면 됩니다.
- "AI 초안 생성"은 미리 정의된 텍스트를 보여주는 목업입니다. 실제 모델 호출로 교체하세요.
